CHANGELOG
=========

v1.5.5
------
- Cache class-edit permissions per request and load a teacher's editable
  classes once, removing repeated permission queries from draft listings.
- Build the import roster name index once instead of scanning the roster for
  every preview row.
- Use the detected workbook column count for import mapping validation instead
  of relying on the first row width.
- Normalize worksheet metadata comparison so blank rows and header position do
  not reject otherwise matching multi-sheet imports.
- Stop treating positive numeric scores such as +5 as spreadsheet formulas and
  escape translated confirmation prompts safely.
- Cap retained import previews per user to reduce session payload.

v1.5.4
------
- Validate every worksheet in an uploaded workbook and merge data rows only
  when assessment metadata and column headers match.
- Reject workbooks whose worksheets describe different assessments instead of
  silently importing only the first sheet.
- Recognize the Chinese 分值 score header used by the generated template.

v1.5.3
------
- Fix saved-draft action links so Resume, Import, Export and Discard receive
  the draft ID from the table row.
- Make Import Scores, Export Template and Export Scores direct links: exports no
  longer submit the assessment form, require assessment metadata, or leave the
  button spinning.
- Keep the assessment name, description and date with the student roster in one
  worksheet, and detect headers after that metadata preamble during import.
- Add Previous Assessment / Next Assessment navigation for saved drafts.
- Use a standard Gibbon footer row for Save Draft, Export Scores and Review.

v1.5.2
------
- Keep the manual Save, Export Scores and Review actions on one compact row.
- Show the fixed assessment scale as a read-only value.
- Split top-level Import Scores / Export Template from bottom Export Scores.
- Let teachers explicitly overwrite a conflicting draft with this tab, while
  retaining Reload latest as the safe secondary action.
- Include assessment name, description and date in exported workbooks as
  metadata without adding those fields to the import mapping.
- Skip blank imported score/comment cells and overwrite every nonblank imported
  value without an additional overwrite-mode choice.
- Restore descriptor-based default comments without replacing teacher-edited
  text, and keep comment-library controls on one compact row.
- Flush queued score changes through a shared loop before manual submission.

v1.5.1
------
- Rebuild the single-assessment editor around one aligned Student, Assessment
  and Comment row per student with editable score/grade inputs.
- Remove checkboxes, selection, bulk entry, undo and the Quick Entry block.
- Add All, Missing and Invalid filtering and Enter-to-next-visible-row entry.
- Move save-first Import Scores and Export Current Scores to the editor action
  area and add grade suggestions through a standard datalist.
- Register the autosave endpoint in the existing installed action URL map
  through a repeat-safe 1.5.1 upgrade migration.

v1.5.0
------
- Add debounced server-side autosave for the standard single-assessment draft.
- Show explicit Unsaved, Saving, Saved, Offline, authentication and Conflict
  states while preserving manual Save, Review, Import and Export behavior.
- Bind autosave to the existing private draft revision; new drafts also use an
  advisory lock, random key and monotonic sequence for idempotent recovery.
- Flush pending autosave before manual submission and never trigger Review or
  Publish automatically. Browser storage is not used as a score source.
- Render the autosave reload action with Gibbon's standard Button component.
- Require the full teacher assessment permission set when discarding a draft.
- Reject missing or zero draft revisions before save, publish or discard.

v1.4.1
------
- Rebuild Score Log entry, review and import screens with standard Gibbon forms,
  form tables, grade-scale controls and data tables.
- Remove the custom entry-grid styling, column controls and colour palette.
- Limit each draft to one assessment with a fixed class and attainment scale.

v1.4.0
------
- Add Next Missing navigation with Alt+N and Enter shortcuts, active-column
  selection and an Only Missing row filter.
- Add selected-student bulk fill and clear with live affected-count preview,
  manual-edit invalidation and revision-bound undo.
- Fill changes blank scores only unless Overwrite existing scores is explicitly
  checked and confirmed; Clear requires its own confirmation.
- Bulk actions operate only on visible checked students and selections reset
  when the active assessment column changes.
- Add a private reusable comment library with creator-bound add, edit and
  delete actions plus non-destructive in-drawer comment appending.
- Reuse a previous assessment's structure without copying scores or comments.

v1.3.0
------
- Add a multi-assessment entry grid with 1–10 independently configured
  assessment columns sharing one class and roster.
- Match the official Formal Assessment column and entry field contract,
  including write-data permission parity and exact grade-scale descriptors.
- Require configured Formal Assessment types and descriptions before a column
  can be published, matching the official column validators.
- Require an official scale-grade row for every entered numeric mark instead of
  inventing a fallback descriptor.
- Accept numeric scale grades entered with or without a trailing percent sign
  and store the exact configured scale value.
- Keep one draft revision and a versioned payload; existing single-assessment
  drafts are adapted automatically.
- Publish every assessment column and entry set in one all-or-none transaction.
- Let import and template downloads target one explicitly selected column.
- Add horizontal grid scrolling, sticky student names, comment drawers and live
  entered/missing/invalid counts.

v1.2.4
------
- Add safe Save and Import Scores and Save and Export Current Scores actions to
  the draft editor.

v1.2.3
------
- Align the score-entry and Saved Drafts layouts with official Gibbon controls.
- Keep the fixed-width desktop grid while enlarging score inputs and auto-sizing
  compact comments up to four lines.
- Use responsive per-student cards at narrow widths.
- Remove unsafe unsaved import/export navigation from the live editor.

v1.2.2
------
- Improve the score-entry table proportions, grouped headers and mobile card layout.
- Put Import Scores and Export Current Scores in the standard draft workflow.
- Standardize Saved Drafts action-column layout and mobile action menus.

v1.2.1
------
- Add a dedicated Saved Drafts page with progress, revision and last-saved
  details.
- Add Resume and revision-bound Discard actions to saved drafts.
- Add a Saved Drafts header action to the assessment workflow.
- Carry forward the 1.1.1 hotfix that quotes the reserved `numeric` scale
  column in draft and publish queries.

v1.2.0
------
- Add CSV, XLSX and tab-separated paste import for score drafts.
- Auto-detect student identifier and score columns, including headerless
  two-column name/score and ID/score pastes.
- Preview matched, unknown, ambiguous, duplicate, invalid and overwrite rows
  before atomically applying changes to the private draft.
- Preserve manual draft values by default and require confirmation to overwrite.
- Reject spreadsheet formula cells without evaluating them.
- Add a roster-based XLSX round-trip template prefilled with current draft
  scores and comments.

v1.1.1
------
- Quote the reserved `numeric` column when loading the selected assessment scale.

v1.1.0
------
- Add private, resumable whole-class drafts with revision checks; core Formal
  Assessment columns are created only at publication.
- Allow creators to discard a private draft with a CSRF-protected action.
- Re-resolve the current roster on reopen and publish, with visible roster changes.
- Add a review-and-publish gate with entered, missing and invalid row counts.
- Require explicit confirmation before publishing students without scores.
- Preserve draft values across validation and class-roster changes.

v1.0.1
------
- Add strict assessment-date validation.
- Apply reviewed Simplified Chinese terminology for assessment workflows.

v1.0.0
------
- Added strict POST, CSRF, permission, assessment type and completion-date validation.
- Added finite-score normalisation and configurable maximum-score parsing.
- Added English source strings and Simplified Chinese translations.
- Added regression tests for score and assessment-type helpers.

v0.0.01
-------
- Refactored the module for readability and safer database writes.
- Fixed the blank page after creating an assessment.
- Default and require the complete date so new grades are visible to students, parents and reports.
- Validate class access, students, scales and scores on the server.
